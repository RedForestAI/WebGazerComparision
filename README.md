# WebGazer FPS / Latency Benchmark

A browser-based tool for measuring [WebGazer.js](https://webgazer.cs.brown.edu/) gaze prediction performance — real-time FPS, latency statistics, sparkline charts, and CSV export.

Built as a companion benchmark for [WebEyeTrack](https://github.com/RedForestAI/WebEyeTrack).

## Usage

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Open the app and click **Start WebGazer**
4. Allow camera access and wait ~5 seconds for warm-up
5. Use **Export CSV** to download raw prediction data

## Deployment

This project is deployed to GitHub Pages automatically on push to `main`.
